# Canonical Visual Acceptance Contract

Canonical Macro Regime, Instrument Research, and Portfolio Risk artifacts are
release-gated static decision-support packets. Opened HTML must remain offline,
read-only, public-fixture safe, and incapable of broker, runtime, or order calls.

## Automated Matrix

- Complete: all 15 views at 1200, 700, 736, and 320 px (60 cases).
- Degraded: all 15 views for `partial`, `stale`, and `source_error` at 736 and
  320 px (90 cases).
- Dark: every complete view at 736 and 320 px, plus every degraded Overview at
  those widths (48 cases).
- Gallery: 12 approved captures with identity, dimensions, nonblank state, and
  hash linkage to the canonical HTML.

The gate checks reflow, overflow, clipping, critical-content visibility,
selected-state parity, keyboard navigation, visible focus, chart readiness,
offline requests, no-JS Overview semantics, evidence-gap visibility, static API
prohibitions, performance budgets, privacy sentinels, and exact distribution
mirrors. A failed run preserves screenshots, DOM offenders, and manifest diffs.

## Privacy And Safety

Scan source snapshots, generated JSON/HTML/manifests, PNG metadata, active
READMEs, and visual documentation. Reject credentials, account identifiers,
private absolute paths, broker raw responses, private runtime material, and
user-generated chart sentinels. Never replace stale or failed evidence with a
fresh-looking fallback or Price Action.

## Human And Host Gate

Automated acceptance must pass before human review. Human review is mandatory
and cannot override an automated failure. One complete artifact per Board must
also pass a recorded real Codex inline smoke using exact HTML bytes. A generic
browser, screenshot, iframe, or browser-wrapper run cannot be recorded as Codex
inline evidence.

Public README replacement and legacy static-SVG retirement remain a separate,
explicitly approved cutover. This gate must not perform that cutover.
