# 市场快照

同目录的 `capability.json` 定义交付边界与离线验收场景。

```mars-skill-policy
{"delivery":"markdown_snapshot","forbidden_effects":["account_access","broker_write","drive_write","persistent_state"]}
```

交付一次性中文 Markdown。默认使用以下骨架；用户明确要求不同表达时可以调整版式，但保留
“当前状态、核心指标、情景与触发、风险暴露、数据缺口”及逐项来源/`as_of`。

1. **当前状态**：一句可证伪的宏观与风险偏好判断，分开事实与推断。
2. **核心指标**：优先覆盖利率与通胀（2Y、10Y、30Y、CPI、核心 CPI、PPI）、风险偏好与信用（VIX、VIX3M、HYG/LQD）、美元与大宗商品（DXY、WTI 原油、黄金）。单项无可靠数据时标为“数据不可用”和原因；不因缺一项取消整份快照。
3. **近期催化剂**：只列与当前判断有关的少量已核实事项；需要完整事件清单时改用“市场催化剂简报”。
4. **情景与触发、风险暴露、数据缺口**：给出条件与观察点，不给出账户、仓位、订单或交易指令。

## 数据获取

按字段找来源，先查数据的发布者或交易所，再用公开报价补足可用的 EOD/延迟市场价格：

| 字段 | 首选来源 | 补充路径与标记 |
| --- | --- | --- |
| 2Y、10Y、30Y | 美国财政部 Daily Treasury Par Yield Curve | 使用发布日期和交易日，不把盘中报价当作官方曲线。 |
| CPI、核心 CPI、PPI | 美国劳工统计局（BLS）当前新闻稿/数据库 | 使用对应统计月份、环比或同比口径与发布日期。 |
| PCE、GDP、个人收入（仅相关时） | 美国经济分析局（BEA）新闻稿/数据表 | 不以媒体二次转述替代原始发布。 |
| VIX、VIX3M | Cboe 官方 VIX 与期限结构页面/历史数据 | 标明官方数据的延迟和实际时间戳。 |
| HYG/LQD、DXY、WTI、黄金 | 已配置且覆盖该符号时的本地 FMP EOD；否则可访问的公开报价 | 同一比值尽量使用同一来源和同一收盘日；公开报价必须标为 best-effort/延迟，不暗示实时或官方。 |
| 近期催化剂 | 对应发布机构、央行、公司 IR、政府或监管公告 | 正在发展的风险可用可信报道，但标为“已报道”或“待官方确认”。 |

先用字段名和上述机构定位原始页面；每个已填数字或事件都写来源链接（可得时）、数据
时间/发布日期和本次研究 `as_of`。可选 FMP 只在用户已在本地私密配置、且权限覆盖所需
EOD 数据时使用；不得索取、回显、保存或写入任何凭据。不要等待所有字段齐全，也不要把
不同时间点的价格伪装成同一时点的比较。

本 Skill 无状态、只读。不要访问账户、持仓、订单，不执行交易，不写入 Drive 或持久化
研究结果。
