# 火星投研助手 1.0 规格

Status: accepted
Updated: 2026-07-25

## 产品目标

火星投研助手是一个只以 Skill 形式发布的交易研究助手。它把宏观、
行业事件、公司基本面和价格行为整理成可复核的决策支持，不创建、
修改、取消或提交真实订单。

当前产品只有一个券商 Provider：IBKR。不存在默认券商选择、自动切换、
多券商聚合或兼容别名。

## 三个入口

### 未指定标的的 Daily Ops

```text
检查 IBKR 工具可见性
-> 逐字段获取 Macro 数据
-> Macro Preflight
-> 完整 standalone Board 或一个 Data Acquisition Blocker
-> 询问是否读取 IBKR 持仓，或直接研究标的
```

Macro Board 是未指定标的启动的第一份决策产物。运行时状态、能力检查
和市场摘要不能替代它。

### 持仓展示

只有用户针对本次请求明确同意后，才读取 IBKR 持仓和现金。展示字段
固定为：

- 券商；
- 标的；
- 数量；
- 最新价格；
- 市值；
- 成本；
- 未实现盈亏；
- 币种；
- 现金；
- 读取时间。

缺失字段显示 `不可用`。输出不包含账户标识、原始响应、订单、集中度、
杠杆、Greeks、压力测试、风险评分或组合建议，也不会自动进入 PA。

### 指定标的研究

用户点名标的后，可执行行业事件、基本面、估值、催化、反方观点和
4H Price Action。用户明确缩小范围时按其范围执行。

券商行情和 OHLCV 只使用 IBKR。基本面与事件可使用公司公告、监管文件
和直接打开的权威公开来源。

## Macro 字段路由

每个字段独立执行：

1. 精确且已验证的 IBKR 字段；
2. 已登记的官方来源；
3. Web Search 定位权威页面，并直接打开验证；
4. 仍无法确认字段身份、单位、时间或完整收盘口径时返回 Blocker。

Web Search 只是发现路径，搜索摘要不能成为数值来源。使用公开兜底时，
用户可见结果必须说明受影响字段、最终权威来源和参考日期。

目前 IBKR 收益率映射只承认已验证的 TNX 和 TYX 合约，固定使用 0.1
缩放并验证完成日线收盘。2Y 没有精确 IBKR 映射时使用美国财政部收益率
曲线。拍卖高收益率、ETF 代理、仅 ticker 匹配或盘中值均不能替代。

## Macro 交付合同

- 所有必需字段完整：复用现有四视图 standalone Board。
- 任一必需字段不完整：只返回一个批量 Data Acquisition Blocker。
- 不生成 partial Board、placeholder、代理字段或纯文字替代品。
- 市场字段使用最近共同完成收盘；官方字段保留实际参考期。
- Board 继续通过 `ResearchResult -> DeliveryPacket` 生成，不新增第二套
  渲染器。

## 数据与隐私

- 能力检查只检测当前任务是否暴露 IBKR 工具，不读取账户或行情。
- Macro 市场数据读取不授权持仓读取。
- 持仓读取需要每次明确同意。
- 私人运行时、账户、凭证、原始券商响应和用户图表不进入公开仓库。
- 旧券商选择配置已退休，不读取、不迁移，也不能重新激活已删除路径。

## 当前明确不支持

- 任何第二券商 Provider；
- 多券商切换、合并或对账；
- Portfolio Risk Panel；
- 自动 PA、自动标的选择或自动交易指导；
- 搜索摘要、拍卖收益率或 ETF 代理充当精确 Macro 字段；
- 订单操作。

## 验收

发布前至少验证：

- IBKR-only Provider 边界；
- TNX/TYX 身份、缩放和完成收盘；
- 官方 2Y 与当前 TGA schema；
- Macro Board-or-Blocker；
- 公开兜底披露；
- 明确同意后的 IBKR Holdings Display；
- IBKR OHLCV；
- 当前 Skill、模板、夹具和用户文档无第二券商活跃支持；
- portable install smoke 和 `git diff --check`。
