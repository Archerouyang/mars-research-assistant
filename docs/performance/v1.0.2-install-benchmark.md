# v1.0.2 安装与渲染性能基线

测试日期：2026-07-30（Asia/Shanghai）。本记录是 v1.0.2 开发分支的本地验收证据，不代表线上
发布或不同网络环境下的承诺。

## 测量范围

为避免把网络拉取质量混入包体优化，安装对比只计入同一台机器上的本地安装阶段：旧流程的
运行包暂存、Python/依赖环境准备与校验，和新流程的 Skills CLI 运行包发现及复制。npm registry
解析、GitHub 拉取和后续技术面首次依赖下载单独报告，不作为 CI 时间上限。

## 结果

| 指标 | 旧下载执行安装器 | 新 Skills CLI 复制安装 | 变化 |
| --- | ---: | ---: | ---: |
| 本地安装阶段耗时 | 约 40.0 秒 | 6.8 秒 | 约快 83% |
| 安装时 Python 环境 | 预建 `.venv` | 不创建 | 消除首装依赖准备 |
| 安装后的额外环境 | 约 89 MiB、4,154 个条目 | 0 | 消除 |
| 被复制的运行时源文件 | 白名单副本 | 36 个文件、约 391,548 bytes | 独立最小包 |

旧流程的 40 秒为同机、带本地 uv 缓存的冷候选安装测量；因此它没有把解释器/依赖的外网下载
误记为包复制成本。新流程在新建临时 Git 项目中执行本地路径的
`npx skills add … --skill mars-research-assistant --agent codex --copy --yes`，Skills CLI 报告复制
完成，随后检查到安装目录只有运行包文件，磁盘占用约 472 KiB，没有测试、文档或 README。

6.8 秒相对 40.0 秒减少约 83%，超过“至少 50%”的 v1.0.2 验收线。首次没有 npm 缓存时需要额外
下载 Skills CLI；从 GitHub 安装时还会产生仓库获取时间。这两项外部网络变量应在准备发布时另行
报告，而非被宣称为确定的本地性能。

## 离线渲染预算

同次组合验证实测：

| 工件 | 时间 | 预算 |
| --- | ---: | ---: |
| 个股快览 fixture Markdown | 0.026 秒 | ≤ 1 秒 |
| 深度个股研究 fixture Markdown | 0.025 秒 | ≤ 1 秒 |

完整运行包为 36 个文件、391,548 bytes，低于 60 个文件和 1 MiB 的限制。上述 renderer 使用
标准库和本地 fixture；不访问网络、账户、Drive 或浏览器。

## 按需技术面环境检查

为确认“安装不预建、实际调用才准备”没有破坏技术面能力，另在一个全新的临时目录运行
`uv sync --locked --offline`，使用已有 Python 3.12 与本地 uv 缓存。它成功安装 26 个锁定依赖
（含 yfinance 1.5.2），工具墙钟时间为 5.7 秒；临时目录随后已删除，运行包未写入 `.venv`。
这不是公开安装时间，也不计入上表的新流程 6.8 秒。
