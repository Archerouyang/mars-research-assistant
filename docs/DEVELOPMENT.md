# Mars Skills 开发说明

## 结构与原则

- 开发仓库根目录保存测试、文档和开发脚本；唯一可安装运行包位于
  `skills/mars-research-assistant/`。
- 每个子 Skill 只完成一种交付；Ask Mars 只建议，不自动执行其他 Skill。
- 最终文字研究必须创建用户可见的本地 Markdown 工件。默认目录是活动工作目录的
  `mars-research/`，文件名唯一且不覆盖；PDF/PPT 只在用户要求或显著提升可读性时额外生成。
- 不访问账户、持仓、订单或交易执行能力；不在代码、测试、文档或日志中保存用户凭据。
- 公开安装使用 `npx skills add`，不维护下载执行 shell 的安装器。uv/yfinance 只由技术面
  分析在首次实际调用时按锁文件准备。

## 验证

组合级离线验收入口：

```bash
bash scripts/verify-mars-skills.sh
```

它验证运行包大小/文件数、Skill 合同、公开安装指令、来源边界以及快览和深度研究的确定性
Markdown fixture。测试只在临时目录写入，不调用市场数据、新闻、Google Drive、浏览器、
经纪商或任何需要凭据的服务。

新增 Skill 必须有明确的触发描述、100 行以内的 `SKILL.md`、`capability.json` 和可离线验证的
交付契约。需要重复且确定性的计算时，脚本应位于运行包内；复杂或罕见的说明应放到一层引用
文件，避免把默认上下文做重。

## 提交前检查

- 运行组合级验收与相关 focused test。
- 确认运行包没有测试、README、开发文档、Git 元数据或预建 `.venv`。
- 确认不引入私有绝对路径、凭据、外部服务调用或交易写操作。
- 确认任何研究结论、来源、`as_of` 与数据缺口都在本地工件中可审计。
