# Trading Research System 0.2.0 Cleanup Ledger

This ledger records the replace-not-layer cleanup required by ADR 0009 and
issue #72. It classifies public repository behavior only. Private runtime files
and databases are outside this cleanup and are never deleted automatically.

## Retained

| Surface | Retained boundary |
| --- | --- |
| Canonical Skill | `skills/trading-research-system/` remains the only behavior source. |
| Native wrappers | `plugins/trading-research-system/` remains generated by `scripts/sync_native_plugin.py`. |
| Research delivery | `research_result.py`, `inline_visual.py`, and purpose-specific Macro, Instrument, Portfolio, and Price Action adapters. |
| Canonical artifacts | ArtifactPacket core, adapters, immutable serialization, manifests, and focused compatibility self-test. |
| Read-only inputs | Runtime health, explicit runtime preparation, saved broker adapters, Longbridge macro/OHLCV adapters, and published Alpha inputs with no ranking mutation. |
| Private boundary | Blank templates and explicit local-runtime helpers; no private state is shipped or inferred. |
| Visual export | `export_inline_png.mjs`, invoked only after the user selects an inline panel for export. |

## Migrated

| 0.1.x ownership | 0.2.0 destination |
| --- | --- |
| Large router and workflow prose | Small `SKILL.md` plus intent-specific progressive references. |
| Fixed output templates | Validated `ResearchResult` fields and deterministic Markdown rendering. |
| Standalone visual instructions | Purpose-specific adapters behind `DeliveryPacket.inline_html`. |
| Broad source and privacy prose | `references/safety-and-sources.md` plus validator invariants. |
| Macro/Portfolio/PA formatting rules | Frozen `macro-research.md`, `portfolio-research.md`, and `price-action.md` references, accepted manually in chat. |
| Broad release verification | `scripts/verify-plugin.sh`, one isolated install smoke, and manual artifact acceptance. |

## Removed

| Class | Removed content and reason |
| --- | --- |
| Mutable database feature | `kvn_leaderboard.py`, KVN SQLite defaults, KVN snapshot fixtures, and leaderboard contracts. No supported 0.2.0 caller owns a mutable public KVN store. |
| Legacy trade compatibility | `import_legacy_active_csv.py`, `trade_records.py`, `update_trade_record.py`, legacy CSV fixtures, and their tests. Private records are not migrated or deleted. |
| Prompt-wording contracts | Router, workflow, automation, source-routing, macro-data, PA wording, and report-intake contract verifiers tied to 0.1.x prose. |
| Redundant browser suites | Multi-board browser wrappers, screenshot matrices, visual-acceptance harnesses, and static gallery staging checks. Manual inline acceptance is authoritative. |
| Redundant behavior matrices | Repository-level startup, reconciliation, and setup-key matrices after the result seam became the external contract. |
| Duplicated board facades | Obsolete per-board artifact wrappers superseded by shared adapters and `research_board_artifact.py`. |
| Fixture corpus | Expected prose outputs, full private-style runtime fixtures, broker order/execution fixtures, and old router inputs with no active focused test. |
| Generated state | Repository `__pycache__`, `*.pyc`, SQLite/database files, and other generated caches. Verification runs with isolated scratch paths and bytecode disabled. |
| Obsolete gate | `scripts/verify-mvp.sh`, Contract Suite orchestration, and their self-tests. The minimal release gate is now `scripts/verify-plugin.sh`. |

## Verification Boundary

The release candidate must satisfy:

1. no tracked or untracked `__pycache__`, `*.pyc`, `*.db`, `*.sqlite`, or
   `*.sqlite3` under public package roots;
2. no active README, roadmap, smoke script, or current design document points
   to removed 0.1.x files;
3. canonical and generated native wrappers are synchronized;
4. `bash scripts/verify-plugin.sh` passes;
5. `bash scripts/smoke-portable-skill-install.sh` passes in isolated homes;
6. the user manually accepts representative inline artifacts before public
   cutover.
