# Mars Research Assistant v1.0.2 设计基线

本文记录 v1.0.2 开发分支已确认的实现边界；它不是发布公告。

## 目标

1. 将可安装内容收敛为一个轻量 Skill 运行包，并以 `npx skills add` 作为唯一公开入口。
2. 将原单一标的研究拆分为默认轻量的个股快览与显式触发的深度个股研究。
3. 所有最终文字研究通过用户可见的本地 Markdown 源稿交付，并用离线 fixture 验证速度与结构。

## 运行包与安装

开发仓库保留测试、文档和开发脚本；`skills/mars-research-assistant/` 是唯一运行包根。它包含根
入口、七个子 Skill、必要脚本、锁文件和 vendored 图表资源，但不包含测试、README、开发文档、
Git 元数据或预建 `.venv`。

```text
skills/mars-research-assistant/
├── SKILL.md
├── skills/
│   ├── instrument-research/       # 对外名称：个股快览
│   ├── deep-equity-research/
│   └── 其余五个子 Skill
└── pyproject.toml / uv.lock        # 仅技术面首次调用时使用
```

用户使用：

```bash
npx skills add archerthegoat/mars-research-assistant \
  --skill mars-research-assistant \
  --agent codex \
  --global \
  --copy
```

Skills CLI 只复制运行包；它不触发 Python、uv 或 yfinance 的预建。技术面分析首次实际调用时，
才检查 uv 并根据锁文件在包内创建环境。使用 npx 是可行的：本地 Skills CLI 已发现唯一根 Skill，
并在临时 Git 项目实际复制了 36 个运行时文件；网络拉取耗时取决于 npm 与 GitHub，不作为离线
包体或渲染预算的一部分。

## 个股研究路由与工件

- 未明确要求深度的单标的请求使用“个股快览”（稳定机器标识 `instrument-research`）。它在
  身份唯一核验后交付带 `as_of` 的价格、规模/估值锚、最新财务摘要，30 天内 3–5 条直接相关
  公司公告/新闻，以及来源、时间戳和数据缺口。
- 出现深度研究、估值、财报复盘、投资备忘录、竞争格局或建模时使用
  `deep-equity-research`。它固定交付九章，并使用四项跨市场财报质量检查。
- 公司名称、ticker、交易所和发行人不能唯一对应时，两类 Skill 都先要求澄清，不创建工件。
- 最终文字工件默认创建在活动工作目录的 `mars-research/`，以日期、symbol、类型和递增后缀
  组成唯一文件名。不得覆盖既有文件或向安装目录写入。PDF/PPT 仅在用户要求或确有显著呈现
  增益时额外生成；Drive 归档仍须独立确认。

## 深度研究与估值

九章固定为：研究范围与核心判断；公司与商业模式；行业与竞争格局；管理层、治理与资本配置；
财务表现与质量核查；预期差、催化剂与关键跟踪项；三情景 DCF/反向 DCF；风险、反方论点与可
证伪条件；来源、时间戳、假设与数据缺口。

质量核查逐项提供来源或缺口：收入/利润/经营现金流一致性、现金转换与应计质量、应收账款及
递延收入相对收入的异常、股本稀释/SBC/审计意见/治理红旗。不会输出伪精确等级，也不把依赖
特定市场字段的 Beneish M-Score 放入通用核心。

三情景 DCF 只在来源可追溯 JSON 同时具备价格、股本、净债务、WACC、永续增长率和三条自由
现金流路径时运行；缺少输入时，估值章保留并明确数据缺口。反向 DCF 还需要当前自由现金流和
预测期。脚本只计算、展示假设和结果，不将结论映射为买卖、仓位或执行指令。

## 验收

`scripts/verify_mars_skills.py` 与 `bash scripts/verify-mars-skills.sh` 在离线 fixture 上验证：

- 七个子 Skill、根入口、能力合同及本地交付边界；
- 运行包不超过 60 个文件和 1 MiB；
- 个股快览和深度研究各在 1 秒内生成 Markdown；
- 深度研究的九章、四项质量检查，以及估值输入缺口分支；
- 运行包不包含旧安装器、测试、开发文档或预建环境。

安装性能的实测基线与方法记录在
[v1.0.2-install-benchmark.md](performance/v1.0.2-install-benchmark.md)。
