# Mars Research Assistant v1.0.2

发布日期：2026-07-30

v1.0.2 将 Mars 收敛为一个可完成明确任务的轻量 Skill 运行包：默认提供可审计的个股快览；只有用户明确提出估值、建模、财报复盘或竞争分析时，才进入深度个股研究。

## 安装方式变更

`curl` 下载执行和旧的自定义安装器已移除。请使用 Skills CLI：

```bash
npx skills add archerthegoat/mars-research-assistant --skill mars-research-assistant --agent codex --global --copy
```

安装只复制运行时所需内容；不会复制测试、开发文档、仓库元数据或预建 Python 环境。技术面分析的锁定 Python 依赖只在首次实际请求技术分析时按需准备。

## 新增与改进

### 个股快览（`instrument-research`）

- 保留现有机器 ID，面向用户显示为“个股快览”。
- 在生成报告前核验公司名称、Ticker、交易所与发行人；身份不唯一时要求澄清且不生成报告。
- 输出一组带 `as_of` 的关键公开数据：价格、规模或估值锚、最新财务摘要。
- 输出最近 30 天内 3–5 条与发行人直接相关的公告或新闻，并披露来源、时间戳与数据缺口。
- 默认不混入估值、技术面、宏观评论或交易建议。

### 深度个股研究（`deep-equity-research`）

- 新增九章结构：研究范围、业务、行业竞争、治理与资本配置、财务质量、催化剂、估值、风险反方观点、来源与缺口。
- 财务质量至少覆盖营收/利润/经营现金流趋势、现金转化与应计、应收/递延收入，以及稀释、SBC、审计与治理旗标。
- 仅在价格、股数、净债务、WACC、永续增长率与 bear/base/bull FCF 等输入均可追溯时运行三情景 DCF；缺项时明确披露估值缺口。
- 可选反向 DCF 会披露输入来源；若目标估值超出可求解区间，不输出伪精确结论。
- 研究结论不包含买卖、仓位或下单指令。

### 本地研究工件

- 所有文字型 Skill 默认在活动工作目录的 `mars-research/` 下生成唯一命名的 Markdown。
- 不覆盖已有文件，也不把研究结果写入全局 Skill 安装目录。
- 每份研究工件保留来源、带时区的 `as_of` 时间戳和明确的数据缺口；晚于研究截点的来源会被拒绝。
- PDF 或 PowerPoint 仅在用户明确要求或可视化明显更优时生成。

## 路由与兼容性

- 单一股票、未指定深度的请求默认进入“个股快览”。
- 明确要求深度研究、估值、建模、财报复盘、竞争分析或投资备忘录时，路由至 `deep-equity-research`。
- 根 Skill 保留七个内部能力：Ask Mars、市场催化剂简报、市场快照、个股快览、深度个股研究、技术分析与 Drive 写回。

## 性能与验证

- 运行包：36 个文件、403,639 bytes，低于 60 文件和 1 MiB 限制。
- 相同机器上的本地安装阶段从约 40.0 秒降至 6.8 秒，约快 83%；网络拉取时间单独看待。
- 个股快览与深度研究 fixture 渲染均低于 1 秒；发布验收实测约 0.03 秒。
- 发布前完成运行包边界、Markdown 不覆盖、严格来源时间、锁定依赖同步、完整单元测试与公开 `npx` 安装验证。

## 升级提示

旧 `curl` 或自定义安装脚本不再是受支持入口。重新执行上方的 `npx skills add` 命令即可安装 v1.0.2；已有依赖 `instrument-research` 机器 ID 的调用可继续使用。
