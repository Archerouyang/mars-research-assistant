# 用运行包预算验证 Skill 性能

v1.0.2 以用户安装和可重复本地交付为性能对象：公开 npx 运行包不超过 1 MiB、60 个文件，且不在安装时预建 uv/yfinance 环境；个股快览和深度个股研究在离线 fixture 下各自生成本地 Markdown 的时间不超过 1 秒。相同机器上，新 npx 流程相对旧 curl 流程必须记录至少 50% 的端到端耗时缩短；网络克隆时间单独报告，不作为 CI 硬门槛。

## Considered Options

- 只缩短开发验收：容易测试，但不改善用户安装和完成研究任务的体验。
- 把公网下载时间设为 CI 上限：贴近用户感受，却会因网络、npm 缓存和 GitHub 状态产生不可重复失败。
- 对运行包和离线工件设确定性预算，并记录同机端到端安装对比：同时约束包体、可控执行成本和实际体验变化。

## Consequences

每项性能优化必须提交优化前后测量结果与相同输入。技术分析的真实 yfinance 调用仍只在发布验收运行一次；其网络与数据供应商等待不成为日常性能测试或定时任务。
