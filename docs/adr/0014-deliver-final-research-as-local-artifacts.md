# 将最终研究交付为本地工件

所有最终研究交付都必须创建用户可见的本地 Markdown 源文件，替代仅在聊天中输出长文本。PDF 或 PowerPoint 只在用户明确要求，或能显著改善图表、比较或叙事时额外生成；本地工件不构成对 Google Drive 写入的授权。

## Considered Options

- 只在对话中交付：最低摩擦，却无法稳定复用、审阅或转换为其他格式。
- 每次强制生成 PDF：视觉一致，但让轻量快览引入不必要的生成成本和格式依赖。
- Markdown 必有、可视化格式按需：保留可审计的文本源稿，并只在有效时增加视觉交付。

## Consequences

Skill 合同可以允许用户可见的本地输出文件，但仍禁止隐藏缓存、未要求的历史记录、自动云端归档和交易写操作。文件命名、目录和覆盖规则必须显式定义，且不覆盖现有研究工件。
