# Limit the Skill to three stateless research Boards

Mars Research Assistant will retain only Macro Regime, Instrument Research, and intent-triggered Price Action Boards. Holdings, Daily Ops, saved plans, reviews, runtime health, Gallery workflows, and their persistence machinery leave the Skill boundary. This deliberately gives up an integrated research workspace so the installed Skill can focus on producing one high-quality, source-backed answer without setup or hidden state; restoring an old workflow is therefore a product-scope decision, not routine compatibility work.
