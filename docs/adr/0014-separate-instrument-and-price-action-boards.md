# Separate company research from Price Action

Instrument Research Board will contain only Overview, Fundamentals, Industry, and Events & Catalysts. It does not include a peer table or peer-company event collection. OHLCV, liquidity, volatility, technical structure, levels, scenarios, and invalidation belong exclusively to Price Action Board, which is generated only when the user asks for timing or trade-plan analysis. This removes an existing mandatory price gate from ordinary company research and accepts two conditional Boards instead of one all-in-one instrument artifact so each request fetches only decision-relevant data.
