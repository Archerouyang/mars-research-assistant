# Require field-first acquisition before rendering Macro Board

Macro Board will declare a small decision-required core field set before selecting a Provider. A deterministic Preflight maps the configured default broker and field-specific official or public fallbacks into those fields; any retained core field that is not exact, fresh, and semantically verified blocks Board generation until acquisition succeeds. A desired signal without a stable direct public source is removed from the versioned field contract rather than becoming a proxy, a waiver, or a partial Board section. This rejects silent proxies and partial Boards while keeping the 1.0 core small and auditable.
