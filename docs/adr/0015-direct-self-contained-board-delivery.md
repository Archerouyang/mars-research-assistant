# Deliver Boards directly as self-contained HTML

Mars Research Assistant will retain the visual language of the three in-scope Boards, but render each required Board directly as one self-contained HTML document alongside its Markdown result. The Skill will not create or consume `ArtifactPacket`, `ResearchResult`, manifests, hash chains, galleries, or any artifact registry. This supersedes those delivery mechanisms for the stateless research scope and trades durable provenance artifacts for a smaller, install-and-use one-shot workflow.
