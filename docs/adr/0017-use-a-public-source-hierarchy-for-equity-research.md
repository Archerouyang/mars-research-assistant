# 为个股研究采用公开来源层级

个股快览与深度个股研究都按同一公开来源层级核验事实：监管披露、交易所和发行人 IR 优先；价格、规模和估值锚使用可公开核验的行情来源并标注 `as_of`；公司公告优先于可信媒体原文。搜索摘要、账户数据、API key 和私有数据不构成研究证据，冲突或缺失必须写入交付物。

## Consequences

每个关键数字和新闻项都必须保留来源与时间。开始取数前，Skill 必须先核验公司名称、代码、
交易所和发行人能唯一对应；不能唯一对应时要求用户澄清，不创建研究工件。身份明确但来源
不足时，Skill 生成带数据缺口的工件，而不是用模型记忆、二手摘要或未标注数字补全结论。
