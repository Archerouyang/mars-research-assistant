# 以通用核心交付深度个股研究

v1.0.2 的深度个股研究采用九章 Markdown/PDF 研报骨架、来源层级与冲突披露、预期差、财报质量核查、可复算的三情景 DCF/反向 DCF 和行业扩展接口。它借鉴 equity-research-skill 的研究纪律，但不在本版本复刻其十六个行业附录或全部估值模型。

## Considered Options

- 完整复刻参考 Skill：覆盖面最广，但显著增加包体、验证矩阵和维护成本，违背普通任务轻量的目标。
- 只改善文字模板：实施很快，却缺少可复算估值与质量门槛，不能形成可靠的深度模式。
- 通用核心加扩展接口：先为所有行业提供同一套可核验主流程，再逐版增加真正改变模型的行业模块。

## Consequences

深度模式必须以本地 Markdown 源稿交付，并在需要时生成 PDF。估值、预期差和风险只形成可审计研究判断，不映射为买入、卖出或持仓比例等交易动作。未来行业附录或额外估值方法必须独立说明其证据、计算和验收契约，不能让默认快览承担其上下文和运行成本。

研报固定使用九章顺序：研究范围与核心判断；公司与商业模式；行业与竞争格局；管理层、
治理与资本配置；财务表现与质量核查；预期差、催化剂与关键跟踪项；三情景 DCF/反向 DCF
（仅数据齐备时）；风险、反方论点与可证伪条件；来源、时间戳、假设与数据缺口。这使离线
fixture 可以验证每一章的存在和估值缺口分支，而不把报告厚度当作研究深度。

三情景 DCF 或反向 DCF 只接收来源可追溯的 JSON 假设集，至少包含价格、股本、净债务、WACC、永续增长率和情景收入或自由现金流。缺少必要输入时，深度研究保留数据缺口并跳过估值，不能用模型记忆补全数值。

财报质量核查采用跨市场的四项最小检查：收入、利润与经营现金流的趋势一致性；现金转换与
应计质量；应收账款及递延收入相对收入的异常变化；股本稀释或 SBC、审计意见与治理红旗。
每项都必须链接到来源，缺失资料明确写为缺口；不输出没有可比依据的 A–D 等级。Beneish
M-Score 等依赖美国市场字段的模型留作未来的可选扩展，不进入 v1.0.2 通用核心。
