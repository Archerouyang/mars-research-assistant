# 以通用核心交付深度个股研究

v1.0.2 的深度个股研究采用九章 Markdown/PDF 研报骨架、来源层级与冲突披露、预期差、财报质量核查、可复算的三情景 DCF/反向 DCF 和行业扩展接口。它借鉴 equity-research-skill 的研究纪律，但不在本版本复刻其十六个行业附录或全部估值模型。

## Considered Options

- 完整复刻参考 Skill：覆盖面最广，但显著增加包体、验证矩阵和维护成本，违背普通任务轻量的目标。
- 只改善文字模板：实施很快，却缺少可复算估值与质量门槛，不能形成可靠的深度模式。
- 通用核心加扩展接口：先为所有行业提供同一套可核验主流程，再逐版增加真正改变模型的行业模块。

## Consequences

深度模式必须以本地 Markdown 源稿交付，并在需要时生成 PDF。未来行业附录或额外估值方法必须独立说明其证据、计算和验收契约，不能让默认快览承担其上下文和运行成本。
