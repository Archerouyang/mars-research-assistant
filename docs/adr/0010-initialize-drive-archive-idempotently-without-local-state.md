# 无本地状态地幂等初始化交易研究中心

Drive 写入可以在明确确认后创建“交易研究中心”根目录、总索引，以及收件箱、每日市场思考、
交易计划、专题研究、周度复盘和案例复盘六个分类目录。初始化每次都从 My Drive 根目录按名称
重新解析实际 Drive ID，并在单次提议与执行中锁定；唯一同名目录存在时只补建缺失项，多个
同名目录时由用户选择。操作不得移动、覆盖、重命名或删除已有内容，也不在本地或安装目录持久化
Drive ID；部分失败时报告已完成项，下次继续补齐。初始化创建的总索引只包含中心说明、六个
分类目录链接，以及交易计划、专题研究、周度复盘和案例复盘四类索引；它不扫描或回填历史
文档，收件箱和每日市场思考不逐条进入总索引。目录初始化与研究归档必须分别展示提议并取得
独立确认；初始化成功后不得自动继续执行原始写入请求。
